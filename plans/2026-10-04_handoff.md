## The decision in one paragraph

neuro-lightbox is for **MRI only** (neurofaune outputs). source-lightbox is
**not frozen**: it stays the EEG tool (source-analytics outputs) and is developed
on its own. Author's reason: *the data are completely different between the two
modalities.* This reverses the 2026-10-02 plan of one successor tool with EEG and
MRI profiles, under which Phases 0–3 here were built.

## Things to know

- **This repository is public and its studies are unpublished.** The fixtures
  keep the real trees' structure but every measured value is synthetic
  (`tests/fixtures/make_fixtures.py`, `tests/fixtures/README.md`). Never commit
  real values.
- **The lab website reads gallery manifests** (`website/public/lib/scanner.php`):
  `title`, `stats.total_figures`, `stats.total_tables`, `stats.paradigm_count`,
  `sources`. Keep these keys in MRI galleries.
- **Principles (author, 2026-10-02):**
  - Built for the analysis package (neurofaune), not for DUET or any study. The
    core-purity test enforces this.
  - The package's outputs must be usable by anyone without this tool.
- **Galleries open straight from disk** (`file://`, no server). The author
  confirmed on 2026-10-04 that no single-file mode is wanted; hosting is only
  for sharing.
- **source-lightbox is alive.**
  - Its `DESIGN_NOTES.md` lists the eight reporting defects as to-dos, with "port
    from neuro-lightbox `1500523`" (`contract.py`, `profiles/eeg/reading.py`,
    `tests/test_contract.py`).
  - The EEG code removed in 3b stays reachable through that commit; don't
    rewrite history.
  - FORGE's gallery scripts run source-lightbox from `~/sandbox/source-lightbox`
    and are unaffected.
